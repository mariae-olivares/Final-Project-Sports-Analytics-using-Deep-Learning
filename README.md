# Final-Project-Sports-Analytics-using-Deep-Learning

Proyecto de análisis deportivo basado en visión computacional y deep learning para la detección de jugadores y balón en un partido de fútbol utilizando YOLOv11.

El sistema procesa un video aéreo capturado con dron y genera analytics en tiempo real, incluyendo:

- detección de jugadores,
- detección y tracking del balón,
- jugadores dentro y fuera del campo,
- jugadores dentro de áreas de penal,
- posición del balón en la cancha.

- Este proyecto fue desarrollado como parte de un proyecto académico enfocado en Deep Learning y Vision Analytics.

El objetivo principal consiste en entrenar un modelo de detección de objetos capaz de identificar:

- jugadores,
- balón de fútbol,
- y generar métricas visuales automáticas sobre el partido.

El modelo fue entrenado utilizando transfer learning sobre YOLOv11n y posteriormente se implementó un pipeline de procesamiento de video completo usando OpenCV.

Debido a temas de privacidad, no se agregará ni los frames de entrenamiento del modelo ni el video de salida. En su lugar se agregará al repositorio una captura de pantalla del video de salida.
